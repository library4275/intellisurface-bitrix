Paste your project URL and publishable/anon key. These are browser client settings; enable Row Level Security and safe policies before production.

SQL to run in Supabase SQL Editor:

create table if not exists public.seats (
  seat_id text primary key,
  floor int not null,
  status text not null default 'available'
    check (status in ('available','occupied','stale','offline')),
  reserved_by text,
  updated_at timestamptz default now()
);
alter table public.seats enable row level security;
-- For a secure production app, create policies using Supabase Auth.
-- Do not leave unrestricted write access enabled.
